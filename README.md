# apple-product-analytics-dashboard-using-figma
An interactive Apple ecosystem product analytics dashboard built from Figma designs, featuring real-time revenue, unit sales, and regional performance metrics.
## 🎨 Figma Design Reference
- **Figma File:** [Apple-themed Interactive Dashboard]([https://www.figma.com/make/i24ILH1I7Ee5aaaLFCyP42/Apple-themed-interactive-dashboard--Community-](https://www.figma.com/make/i24ILH1I7Ee5aaaLFCyP42/Apple-themed-interactive-dashboard--Community-?t=K8QEfIi5gkvnP90n-1))

## 🚀 Key Features
- Interactive dashboard for Apple FY2024 Product Intelligence
- Product performance metrics for iPhone, Mac, iPad, Apple Watch, and AirPods
- Revenue breakdown by region (North America, Europe, Asia-Pacific, India, Rest of World)
